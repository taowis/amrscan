# 0003. Exploratory mapping v2: alleles of a named ResFinder gene

- Status: accepted as exploratory; the primary baseline stays on v1
- Date: 2026-10-18
- Applies to: `benchmark/mappings/ecoli_amrfinder_drug_mapping_v2.tsv` and
  `.json`, generated by
  `scripts/ecoli_research_v1/build_amrfinder_drug_mapping.py --revision 2`;
  `benchmark/cohorts/ecoli_research_v1/baseline_config_mapping_v2.json`
- Written after: the full v1 baseline had been run and its discordant
  endpoints inspected. Everything built on v2 is therefore outcome-informed and
  is reported as exploratory, never in place of v1.

## Context

Reading `unexplained_resistance.tsv` for gentamicin showed 22 R endpoints
without a mapped determinant that carry `rmtE1`, a 16S rRNA methyltransferase.
16S rRNA methyltransferases give high-level resistance to gentamicin,
tobramycin and amikacin. `rmtE1` was listed in `unmapped_determinants.tsv`
(36 isolates).

The cause is in the generator, not in the sources. ResFinder names the gene
`rmtE` with no allele number. AMRFinderPlus reports the allele `rmtE1` under
the node `rmtE`. Under decision 0002, rule 3, a symbol missing from ResFinder
uses the ResFinder genes under its AMRFinderPlus node. The v1 code looked only
at the alleles below the node and never at the node itself, so `rmtE` was
never consulted. The intent of rule 3 was to borrow from the nearest
documented gene, and the parent gene is the nearest.

## Decision

Mapping v2 changes one step. An allele with no ResFinder entry of its own,
whose AMRFinderPlus parent node is itself a ResFinder gene name, takes that
gene's phenotypes. Every other rule, term translation, inference, override
and review flag is the same as in v1. Regenerating with `--revision 1` still
reproduces the committed v1 files byte for byte.

## Effect on the mapping

v2 has 46,728 rules (v1: 46,701). 40 symbols now use their parent gene: 6 had
no rule and 34 had a family consensus. Rules change for 10 determinants:

| Determinant | Change |
| --- | --- |
| `rmtE1`, `rmtE2` | added: amikacin, gentamicin, kanamycin, streptomycin, tobramycin |
| `rmtF1`, `rmtF2` | added: amikacin, gentamicin, tobramycin |
| `rmtB1`, `rmtB3`, `rmtB4` | added: kanamycin |
| `rmtD1` | removed: kanamycin (`rmtD` in ResFinder does not list it) |
| `blaTRU-1` | added: eight beta-lactams |
| `blaNPS-1` | added: ampicillin |

No existing interpretation changes.

## Effect on the baseline

Rebuilt with the same calls, primary variant:

| Antimicrobial | v1 TP/FN/FP/TN | v2 TP/FN/FP/TN | Sensitivity v1 → v2 |
| --- | --- | --- | --- |
| gentamicin | 1074/162/85/6037 | 1096/140/85/6037 | 0.869 → 0.887 |
| kanamycin | 167/11/5/1049 | 167/11/6/1048 | unchanged (specificity 0.995 → 0.994) |

No other study drug changes. On the labels corrected by decision 0004
(`genotype_baseline_20261024`), gentamicin goes from 1129/97/30/6102 to
1151/75/30/6102 (sensitivity 0.921 → 0.939) and kanamycin again gains one FP.

Because the rule was found by looking at
discordant endpoints in this cohort, the v2 numbers are not an independent
estimate. They show the size of the gap, and v2 is the mapping a later,
independent cohort should start from.

## Alternatives considered

- Correcting v1 in place: rejected. v1 was committed before any call was
  read, and changing it would break that record.
- Propagating every node rule down to all alleles: rejected. For broad nodes
  (for example `bla-A`) this would assign phenotypes to unrelated enzymes
  such as `blaHER-3`.
- Hand-adding only `rmtE1`: rejected in favour of a rule stated once and
  applied to the whole catalogue.
