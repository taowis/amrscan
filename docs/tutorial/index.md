# Workshop: finding AMR genes in bacterial assemblies

This workshop is for researchers who have assembled bacterial genomes and want
to screen them for antimicrobial resistance determinants in a way they can
repeat and report. No Nextflow experience is assumed; you should be able to
open a terminal and change directories.

By the end you will be able to:

1. run AMRScan with Docker, Apptainer or Conda;
2. download and pin an AMRFinderPlus database release;
3. run the pipeline on your own assemblies and read the outputs;
4. say what the results do and do not show;
5. move the same run to NCI Gadi.

| Part | Time |
